# Domino Game

## 🁣 Jogo de Dominó em HTML, CSS e JavaScript

O **Domino Game** é uma pequena aplicação de jogo de dominó desenvolvida utilizando as tecnologias fundamentais do *frontend*: **HTML**, **CSS** e **JavaScript**. O projeto demonstra a capacidade de implementar a lógica de um jogo de tabuleiro, manipulação do DOM (Document Object Model) e criação de uma interface interativa sem a necessidade de *frameworks* complexos.

### ✨ Destaques do Projeto

*   **Lógica de Jogo:** Implementação da lógica de distribuição de peças, regras de jogada e controle de pontuação.
*   **Interface Simples:** O jogo possui uma interface simples e funcional, focada na jogabilidade.
*   **Tecnologias Web Padrão:** O projeto é uma demonstração de habilidades em JavaScript (76.3%), CSS (13.1%) e HTML (10.6%).
*   **Assets:** A presença da pasta `assets` sugere o uso de imagens ou ícones para representar as peças do dominó.

### 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso Principal |
| :--- | :--- |
| **HTML5** | Estrutura da página e do tabuleiro de jogo. |
| **CSS3** | Estilização das peças e do layout do jogo. |
| **JavaScript** | Lógica do jogo, manipulação do DOM, controle de eventos e estado. |

### 📂 Estrutura do Projeto

O projeto segue uma estrutura de arquivos simples e direta:

```
Domino-Game/
├── .idea/          # Arquivos de configuração do ambiente de desenvolvimento
├── assets/         # Imagens ou ícones das peças de dominó
├── index.html      # Página principal do jogo
├── script.js       # Lógica principal do jogo em JavaScript
├── styles.css      # Estilização do jogo
└── README.md       # Este arquivo
```

### 🚀 Como Jogar

Para jogar, basta clonar o repositório e abrir o arquivo `index.html` em seu navegador web:

```bash
# 1. Clone o repositório
git clone https://github.com/BrizidoAndre/Domino-Game.git

# 2. Navegue até o diretório do projeto
cd Domino-Game

# 3. Abra o arquivo index.html no seu navegador
# (Exemplo para Linux/macOS)
open index.html
# (Exemplo para Windows)
start index.html
```
